# GitHub Profile README package

## Install it

1. Open https://github.com/Theedzith and create a **public repository named exactly `Theedzith`** if it does not already exist.
2. Add `README.md` from this package to the repository root.
3. Upload the `assets/` folder as-is. The README uses `./assets/profile-banner.svg`.
4. Commit the changes. GitHub will display the README at the top of your profile.

## Before publishing

- Replace the generic “View repositories” links with exact public URLs for Agri Lens, ResumeIQ, and Mindora.
- The email badge currently uses a placeholder address (`theedzithjc@example.com`). Replace it with an address you want to publish, or remove that badge.
- GitHub statistics and streak cards are served by third-party services and may occasionally be unavailable. Remove those image lines if you prefer a fully self-contained profile.
- Review every project description and skill for accuracy before publishing.
